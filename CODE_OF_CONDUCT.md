# Microsoft Open Source Code of Conduct

This project has adopted the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).

We do not tolerate behavior that is disrespectful to our community members or that excludes, intimidates, or causes discomfort to others.

Examples of unacceptable behavior include:
- Violent threats or violent language
- Discriminatory jokes and language
- Posting sexually explicit or violent material
- Personal insults
- Unwelcome sexual attention
- Any harassment or intimidation

If you are subject to or witness unacceptable behavior, please email [opencode@microsoft.com](mailto:opencode@microsoft.com).

For more information, see the [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/).
