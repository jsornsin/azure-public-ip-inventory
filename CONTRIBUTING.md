# Contributing

Thank you for your interest in contributing! Most contributions require you to agree to a Contributor License Agreement (CLA).

## Reporting Issues

- **Bug reports:** Use GitHub Issues with reproduction steps
- **Feature requests:** Describe the use case and benefit
- **Security issues:** Email opencode@microsoft.com (do NOT open public issues)

## Pull Request Process

1. Fork the repo
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Make your changes and test thoroughly
4. Commit with clear messages: `git commit -m "[Type] Description"`
5. Push to your fork: `git push origin feature/my-feature`
6. Open a Pull Request with a clear description

**PR Types:** `[Feature]`, `[Fix]`, `[Docs]`, `[Enhancement]`

## Code Style

- Follow PowerShell best practices
- Use `PascalCase` for function/variable names
- Include comments for complex logic
- Test on both Windows and cross-platform PowerShell

## CLA

When you submit a pull request, a CLA-bot will automatically determine whether you need a CLA. Simply follow the instructions provided.
